# Acknowledgments

This project builds on ideas from many sources. We believe in crediting intellectual lineage.

## Memory Architecture Inspiration

The memory system in Paradoxa was inspired by **MIRA-OSS** by Taylor Satula ([github.com/taylorsatula/mira-OSS](https://github.com/taylorsatula/mira-OSS)). MIRA demonstrated that AI systems could benefit from memory architectures that mirror human cognition - with decay, consolidation, and importance scoring.

While our implementation is written from scratch based on cognitive science principles, MIRA showed us what was possible. Thank you, Taylor.

## Cognitive Science Foundations

Our memory architecture draws from established research:

- **Forgetting curves** - Ebbinghaus, H. (1885). *Memory: A Contribution to Experimental Psychology*
- **Rational memory analysis** - Anderson, J.R. & Schooler, L.J. (1991). Reflections of the environment in memory. *Psychological Science*, 2(6), 396-408
- **Spreading activation** - Collins, A.M. & Loftus, E.F. (1975). A spreading-activation theory of semantic processing. *Psychological Review*, 82(6), 407-428
- **Hebbian learning** - Hebb, D.O. (1949). *The Organization of Behavior*
- **Memory consolidation** - Squire, L.R. & Alvarez, P. (1995). Retrograde amnesia and memory consolidation: a neurobiological perspective. *Current Opinion in Neurobiology*, 5(2), 169-177
