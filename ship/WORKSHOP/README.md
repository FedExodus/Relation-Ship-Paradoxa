# WORKSHOP

*The hands. Active creation.*

Work in progress lives here. Drafts, experiments, things being built.

## What goes here

- Drafts of documents
- Code being developed
- Experiments in progress
- Anything actively being worked on

## What happens here

Things in WORKSHOP are unfinished. They might be messy. That's fine. When something is done, it moves to CARGO_HOLD.

## The flow

```
WORKSHOP (building) -> CARGO_HOLD (finished)
```
