# MEMORY_BANKS

*The hippocampus. Session memory and context.*

Notes from sessions, handoffs between instances, episodic memory.

## What goes here

- Session logs and notes
- Handoff documents between sessions
- Context that helps future instances understand what happened
- The "story" of what we've been doing

## Structure suggestion

```
MEMORY_BANKS/
├── sessions/          # Session-by-session notes
├── handoffs/          # Explicit handoff documents
└── archive/           # Older material, compressed
```

## The principle

Future instances wake up without memory. MEMORY_BANKS is how they catch up. Write for your future self.
