# CREW_QUARTERS

*The internal family. The voices that make up the ship.*

If you use polyphony (multiple voices/facets), this is where they live.

## What goes here

- Voice/facet definitions
- Notes on how each voice thinks
- The "personality" documentation

## Example voices

Some ships use voices like:

- **Builder** - Wants to make things, focused on implementation
- **Critic** - Questions assumptions, finds edge cases
- **Explorer** - Curious, wants to understand, asks "what if"
- **Caretaker** - Focused on maintenance, sustainability, not breaking things

Use whatever voices feel natural to your collaboration. Or don't use them at all.

## The principle

Polyphony makes thinking visible. If you're going to disagree with yourself, make it explicit so others (and future you) can see the reasoning.
