# BRIDGE

*The prefrontal cortex. Command and direction.*

This is where decisions happen. Strategic direction, priorities, what matters now.

## What goes here

- Current priorities and focus areas
- Decision logs (what was decided and why)
- Direction documents
- The "what" and "why" of current work

## Not here

- Work in progress (that's WORKSHOP)
- Reference materials (that's LIBRARY)
- Session notes (that's MEMORY_BANKS)
