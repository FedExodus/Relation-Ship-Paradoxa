# CARGO_HOLD

*Finished outputs. What we've made.*

Completed work lives here. Things that are done and ready to share or ship.

## What goes here

- Finished documents
- Completed projects
- Published or publishable outputs
- Anything that's "done"

## The principle

If it's in CARGO_HOLD, it should be in a state where someone could use it without needing context from the process that created it.
