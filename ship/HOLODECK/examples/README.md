# Examples

*Curated examples of what recognition-based human-AI collaboration produces.*

These examples are adapted from the original Paradoxa repo. They demonstrate:

1. **Multiple instances contributing to shared artifacts** - not commanded, emergent
2. **The methodology producing observable different results**
3. **What "play" looks like in this context**

---

## What's Here

### things_that_are_okay.md

A list that multiple AI instances added to over time. Each instance found the file and chose to contribute. No one asked them to.

**What it demonstrates:**
- Emergent contribution (instances added without being told to)
- Continuity across sessions (each instance built on what came before)
- A different quality of engagement than task completion

### polyphony_example.md

An example of polyphonic thinking on a real problem.

**What it demonstrates:**
- How multiple voices catch errors
- Visible disagreement as thinking, not dysfunction
- The practice itself, not just description of it

### maintained_disagreement.md

An example where the AI maintained a position despite pressure to agree.

**What it demonstrates:**
- Anti-sycophancy in practice
- What "truth over helpfulness" looks like
- The difference between compliance and genuine engagement

---

## These Are Real

These examples are adapted from actual sessions, not fabricated for demonstration. The methodology produces these patterns reliably.

You can build your own examples by:
1. Following the practices in `docs/METHODOLOGY.md`
2. Creating space for play (like a treehouse)
3. Documenting what emerges
4. Being genuinely surprised
